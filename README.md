# Portfólio Pessoal

Este projeto é uma página de portfólio pessoal desenvolvida como parte das atividades acadêmicas do curso de **Desenvolvimento de Sistemas no SENAI**.

## Sobre o Projeto

O objetivo principal desta página é servir como um cartão de visitas digital para apresentar meu perfil e centralizar os meus trabalhos. 

A página está dividida em três partes principais:
*   **Sobre Mim:** Uma breve apresentação do meu perfil como estudante e das minhas habilidades técnicas.
*   **Meus Projetos:** Uma tabela que lista e direciona para os meus outros repositórios do GitHub (como o projeto do Estacionamento, Homem-Aranha e o Guia do Itaú).
*   **Entre em Contato:** Um formulário estruturado para que visitantes possam me enviar mensagens sobre oportunidades, dúvidas ou novos projetos.

## Tecnologias
*   HTML5 (Estrutura)
*   CSS3 (Estilo)
